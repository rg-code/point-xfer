Your own private home for all your bank and card transactions. It runs on your own accounts, so only you can see it. Finds and reconciles all card benefits (coupons) and a lot more.

Get started (about 30 minutes) Copy Minty to your GitHub (fork) Download the code (ZIP)
git clone https://github.com/rg-code/minty.git

The fork is the way to go: it updates itself every week. Use Minty as is, for personal use only (license).
